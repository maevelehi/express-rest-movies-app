# Express REST Movies App
A full-stack project demonstrating a REST-style API built with Node.js, Express, and MySQL, with a frontend that fetches JSON data and dynamically renders it.

## Tech Stack
- Node.js & Express
- MySQL
- HTML, CSS, Vanilla JS

## Features
- REST-style API endpoint for movie data
- MySQL JOIN queries for movie reviews
- Frontend fetches API data and displays it in HTML tables
- Separation of backend and frontend responsibilities

## How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/maevelehi/express-rest-movies-app.git

2. Install dependencies:
   npm install

3. Create a `.env` file with your DB credentials:
    ```bash
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=assignment6

4. Start the server:
    `node assignment6.js`
